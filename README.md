# Commute Cost Calculator

A beginner Python project that calculates the estimated cost of commuting based on driving distance, fuel economy, gas price, and number of commuting days per week.

## What It Does

The program asks the user for:

* Miles driven per day
* Vehicle MPG
* Current gas price
* Number of commuting days per week

It then calculates the estimated:

* Daily fuel cost
* Weekly fuel cost
* Monthly fuel cost
* Yearly fuel cost

## Why I Made This

I created this project as part of my Introduction to Python coursework. I wanted to build something practical that could automate an everyday calculation instead of calculating commuting expenses manually.

## Skills Practiced

* Python variables
* User input
* `int()` and `float()`
* Arithmetic operations
* f-strings
* Formatting decimal values

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder.
4. Run the Python file:

```bash
python commute_calculator.py
```

5. Enter your commute information when prompted.
